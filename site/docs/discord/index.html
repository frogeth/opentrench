Connect Discord

opentrench talks to Discord through a small plugin inside your own Discord app, loaded by Vencord. The plugin feeds opentrench the channels you watch and sends messages for you using Discord's own functions, so to Discord it is simply you using Discord. No token is ever pasted or stored.

What you need: the Discord desktop app, and about five minutes. Vencord only loads third-party plugins from a source build, so the steps below install a few developer tools first. You do this once.

macOS

1. Install the tools

Open Terminal (⌘-Space, type Terminal). Paste each line and press Return.

xcode-select --install

Click Install in the dialog that appears; this gives you git. Then install Node.js and pnpm:

curl -fsSL https://fnm.vercel.app/install | bash
source ~/.zshrc
fnm install 22 && fnm use 22
npm install -g pnpm

Already have Node 20+ and pnpm? Skip that block.

2. Get Vencord and build it with the plugin

cd ~/Documents
git clone https://github.com/Vendicated/Vencord
cd Vencord
pnpm install --frozen-lockfile
mkdir -p src/userplugins
git clone --depth 1 https://github.com/frogeth/opentrench /tmp/opentrench
cp -r /tmp/opentrench/vencord/opentrench-bridge src/userplugins/
pnpm build
pnpm inject

pnpm inject asks which Discord to patch: pick Discord (or PTB/Canary if that is what you use) and confirm.

The plugin folder must end up at ~/Documents/Vencord/src/userplugins/opentrench-bridge, and pnpm build must run after copying it. If you built before copying, run pnpm build again.

3. Turn it on

  1. Fully quit Discord (⌘Q) and open it again.
  2. Open User Settings (gear, bottom left) → Vencord → Plugins. Search OpentrenchBridge and switch it on.
  3. Open opentrench. The discord pill in the top bar turns green within a few seconds. In ⚙ → Accounts → Discord it shows plugin · read + write and your name.

Windows

1. Install the tools

Open PowerShell (Start, type PowerShell). Paste each line and press Enter.

winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e

Close and reopen PowerShell so the new tools are on your path, then:

npm install -g pnpm

Already have git, Node 20+ and pnpm? Skip this step.

2. Get Vencord and build it with the plugin

cd $HOME\Documents
git clone https://github.com/Vendicated/Vencord
cd Vencord
pnpm install --frozen-lockfile
mkdir src\userplugins -Force
git clone --depth 1 https://github.com/frogeth/opentrench $env:TEMP\opentrench
Copy-Item -Recurse $env:TEMP\opentrench\vencord\opentrench-bridge src\userplugins\
pnpm build
pnpm inject

pnpm inject asks which Discord to patch: pick Discord (or PTB/Canary if that is what you use) and confirm. If Windows asks for permission, allow it.

The plugin folder must end up at Documents\Vencord\src\userplugins\opentrench-bridge, and pnpm build must run after copying it. If you built before copying, run pnpm build again.

3. Turn it on

  1. Fully quit Discord (right-click its tray icon → Quit Discord) and open it again.
  2. Open User Settings (gear, bottom left) → Vencord → Plugins. Search OpentrenchBridge and switch it on.
  3. Open opentrench. The discord pill in the top bar turns green within a few seconds. In ⚙ → Accounts → Discord it shows plugin · read + write and your name.

Switching from a token

If you connected Discord with a user token in an earlier version, nothing breaks: the feed keeps reading through the token, and sending is off on that path. Once the plugin connects, opentrench uses it automatically and closes the token session. Then go to ⚙ → Accounts → Discord and click Remove token.

Updating the plugin

When opentrench ships a plugin update (the release notes will say), repeat the copy and build in the Vencord folder, then restart Discord:

cd ~/Documents/Vencord   # Windows: cd $HOME\Documents\Vencord
git pull && pnpm install --frozen-lockfile
git clone --depth 1 https://github.com/frogeth/opentrench /tmp/opentrench   # Windows: $env:TEMP\opentrench
cp -r /tmp/opentrench/vencord/opentrench-bridge src/userplugins/          # Windows: Copy-Item -Recurse -Force ...
pnpm build

Troubleshooting

  • The pill stays red. Is Discord open, and is OpentrenchBridge switched on in Vencord's plugin list? If the plugin is not in the list, the build did not include it: check the folder path, run pnpm build again, restart Discord.
  • Vencord isn't in Discord's settings. pnpm inject did not patch the Discord you run. Run it again and pick the right one.
  • Different port. If opentrench's web page isn't on 3210, set the port in the plugin's settings (Vencord → Plugins → OpentrenchBridge → gear).
  • Discord updated and Vencord stopped loading. Run pnpm inject again in the Vencord folder.
  • Is this allowed? Client mods sit outside Discord's terms. Vencord has a very large user base and Discord has not banned for it; a self-bot (a separate program with your token) is what Discord's detection is built for, which is why opentrench moved away from it.
