Getting started

opentrench runs on your own computer. Install it, connect the accounts you already have, pick the channels you care about, and read the terminal. About ten minutes end to end.

1. Install

  1. Download the latest build for your system from GitHub releases: the .dmg on a Mac, the Setup .exe on Windows.
  2. Mac: open the dmg and drag opentrench to Applications. The build is signed and notarized, so it opens like any other app.
  3. Windows: run the installer. It is not code-signed yet, so SmartScreen shows a warning once: click More info → Run anyway.
  4. Open opentrench. Updates are checked on start and installed from inside the app.

2. Connect Discord

Discord connects through the opentrench plugin for Vencord, which lives inside your own Discord app. There is no token to paste. Follow the Discord guide; it has separate Mac and Windows steps and takes about five minutes once.

Used a token in an earlier version? It keeps working, read-only, until you switch. The switch is your call.

3. Connect Telegram

Telegram uses your own account through Telegram's official API, which Telegram allows. You need an API id and hash, which takes a minute: Telegram guide.

4. Add the channels you want

  • Click the round + at the bottom of the left rail.
  • Pick Discord or Telegram, browse your servers and chats, tick the ones to watch. Click a name first to preview its recent history.
  • Each server and chat becomes an icon in the rail. Drag to reorder, click one to focus on it, click ★ to get back to everything.

5. Read the terminal

  • All Calls: one card per token, newest call first. Who called it, where, how long ago, a gold 1st for a first call or a 🔥 count when several chats called it, market cap at the call and the multiple since. Then image, symbol, volume, market cap, age, address (click to copy), ATH, links, holders, the buy/sell bar and holder security.
  • All Chats: the raw messages, read bottom-up like Discord, with every contract turned into a token strip with a live chart. Click the chat chip on a message to open that channel.
  • Pings: the @ button in the top bar. Everyone who mentioned you, with the messages before and after, jump-to-chat and reply.
  • Click a token's picture for the drill-down: candles on a market-cap axis with every caller pinned, and the full call list.

6. Make it yours

  • Columns: the round + at the right end adds one: calls, chat, Top Callers, Cove, Salpha or J7, over all channels or a few, with filters. Drag the grip to reorder, the right edge to resize, the pencil to edit, × to remove.
  • Alerts: the bell in a column header plays a sound on every new call there. Eight tones to pick from.
  • Favorites: ⋯ next to any name → Favorite caller. They get a crown and their first calls ping you.
  • Bots: ⚙ → Feed → Bots decides which bots show, which count as calls, and which may ping you.
  • J7: paste your J7Tracker session id in ⚙ → Accounts and add a J7 column. Star accounts to get pinged when they tweet; launches off a tweet appear under it.
