Connect Telegram

Telegram uses your own account through Telegram's official API, which Telegram allows. It needs an API id and hash for your account.

1. Get an API id and hash

  1. Go to my.telegram.org and log in with your phone number and the code Telegram sends you.
  2. Click API development tools. Fill in any app title and short name (for example opentrench), leave the rest, click Create application.
  3. Copy the App api_id (a number) and App api_hash (a long string).

2. Log in from opentrench

  1. In opentrench, ⚙ → Accounts → Telegram: paste both and click Save credentials.
  2. Enter your phone number in international format (+15551234567) and click Send code. The code arrives in your Telegram app, not by SMS.
  3. Type the code → Submit code. With two-step verification on, you are asked for that password too.

The telegram pill turns green and stays logged in across restarts. Log out in the same tab ends the session.

Sending

A composer sits under every chat column. Sending is off until you switch it on in ⚙ → Accounts → Telegram. Replies, reactions and a share picker for contract addresses all work through your own account.

Cove and Salpha

The Cove trading bot and the Salpha research bot are Telegram bots. Add a Cove or Salpha column and every buy button and right-click action talks to them through your Telegram session, inside opentrench.
